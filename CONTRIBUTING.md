# Contributing to Atlas

Thank you for your interest in Atlas.

Atlas is an active research project focused on structural topology, persistent identity, ontology construction, and quantitative measurement of complex systems.

The goal is not simply to add features, but to preserve mathematical consistency throughout the framework.

---

# Philosophy

Atlas follows several principles:

- deterministic computation
- reproducible results
- explainable measurements
- modular architecture
- extensive testing
- documentation before complexity

Every contribution should improve one or more of these principles.

---

# Development Workflow

1. Fork the repository

2. Create a feature branch

```
git checkout -b feature/my-feature
```

3. Make changes

4. Add tests

5. Verify

```
pytest
```

6. Commit

```
git commit -m "Describe your change"
```

7. Submit a Pull Request

---

# Coding Standards

## Python

- PEP8 formatting
- type hints encouraged
- descriptive variable names
- no magic numbers
- avoid duplicated logic
- prefer pure functions

---

# Testing

Every structural measurement should include tests.

Whenever possible include

- unit tests
- edge cases
- regression tests

The objective is deterministic reproducibility.

---

# Documentation

Public functions should contain

- purpose
- parameters
- return values
- examples when appropriate

Complex algorithms should include references explaining the underlying methodology.

---

# Issues

Bug reports should include

- operating system
- Python version
- reproduction steps
- expected behavior
- actual behavior

---

# Research Contributions

Research proposals are encouraged when they include

- mathematical justification
- reproducible examples
- references
- computational implications

---
